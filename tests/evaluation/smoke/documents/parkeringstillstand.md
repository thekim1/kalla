# Parkeringstillstånd för rörelsehindrade

## Vem kan få tillstånd?

Du kan få parkeringstillstånd om du har ett varaktigt funktionshinder som gör att du har stora svårigheter att förflytta dig på egen hand. Tillståndet kan gälla dig som förare eller som passagerare.

## Ansökan och läkarintyg

Ansök via e-tjänsten Parkeringstillstånd och bifoga ett läkarintyg och ett foto. Handläggningen tar ungefär fyra veckor.

## Var får jag parkera?

Med tillståndet får du parkera på platser för rörelsehindrade och upp till tre timmar där parkering annars är förbjuden. Tillståndet gäller i hela landet.
